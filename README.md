# FinVault — Android Financial Asset Tracker 

**FinVault** — оффлайн-первое Android-приложение для удобного учета личных финансов, расходов и активов. Проект разработан на основе современных стандартов Android-разработки (**Android Jetpack**, **MVVM**) с акцентом на безопасность данных, автономность и высокую производительность.

---

## Основные возможности

- **Учёт финансов и активов:** Интуитивный интерфейс для управления транзакциями и отслеживания баланса.
- **Биометрическая защита:** Вход в приложение по отпечатку пальца / Face ID с использованием **Biometric API**.
- **Offline-First Хранилище:** Полная автономность работы через **Room DB** без обязательного интернет-соединения.
- **Фоновые задачи:** Автоматическое обновление данных и курсов валют через **WorkManager**.
- **Современный UI:** Адаптивный интерфейс на базе **Material Design** с поддержкой темной и светлой тем.

---

## 🛠 Технологический стек

* **Язык программирования:** Kotlin
* **Архитектура:** MVVM (Model-View-ViewModel)
* **База данных:** Room DB (SQLite)
* **Безопасность:** Biometric API
* **Фоновые процессы:** WorkManager
* **Асинхронность:** Coroutines, Flow
* **UI:** Jetpack / Material Design
* **Среда разработки:** Android Studio
